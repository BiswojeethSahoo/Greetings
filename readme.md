# Time-Based Greeting

Simple Python program to check the time and output a greeting according to the time.

## What it does

- Gets the current time using Python’s time module
- Outputs the current time in `HH:MM:SS` format
- Outputs a greeting according to the hour of the day:
  - **4:00 am – 11:59 am** → Good morning!
  - **12:00 pm – 3:59 pm** → Good afternoon!
  - **4:00 pm – 6:59 pm** → Good evening!
  - **7:00 pm – 3:59 am** → Good night!

## Requirements

- Python 3.x (no additional libraries required)

## Usage

```bash
python Greetings.py
```

## Output

```
The current time is: 14:32:10

Good afternoon!
```
